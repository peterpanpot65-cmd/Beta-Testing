# Mix Analyzer Beta

Public distribution repo for the Mix Analyzer desktop app (macOS & Windows).

## Downloads (v0.1-beta)

- **macOS (.dmg):** https://github.com/peterpanpot65-cmd/Beta-Testing/releases/download/v0.1-beta/MixAnalyzer.dmg
- **Windows (.exe):** https://github.com/peterpanpot65-cmd/Beta-Testing/releases/download/v0.1-beta/Mix.Analyzer_0.1.0_x64-setup.exe

See all releases: https://github.com/peterpanpot65-cmd/Beta-Testing/releases

The build isn't code-signed yet, so your OS will warn you on first open:
- **macOS:** open Terminal and run `xattr -dr com.apple.quarantine "/Applications/Mix Analyzer.app"`, then open it normally.
- **Windows:** when SmartScreen appears, click **More info** -> **Run anyway**.
